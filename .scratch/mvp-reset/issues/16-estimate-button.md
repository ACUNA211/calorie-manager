# Estimate button for unmatched food

Type: build
Status: open
Assignee:
Blocked by: [Today: log food by search](14-today-logging-by-search.md)

## What to build

When nothing local or from USDA fits, an Estimate button asks Claude from the page (the artifact's ask-Claude capability, on the Member's account) for one calorie number for what was typed. The Member accepts or edits it; accepting logs it and saves a Food Library food marked *estimated*. Typing calories by hand is always available; if the capability is unavailable or refused, the button hides.

## Done when

- An unmatched item can be logged with an estimate in one extra tap
- The estimated food is found locally next time
- Declining permission leaves typing calories working
