# Extra Shopping list lines when a Cook grows

Type: build
Status: open
Assignee:
Blocked by: [Shopping list built on Approve](20-shopping-list-from-approve.md)

## What to build

After approval, when a Cook's servings made go up (a grid edit, a Rebalance or the Agent), add a new unticked line for only the extra amount ("+1 can black beans"). Ticked lines are never unticked; when less is needed nothing changes. No Review screen.

## Done when

- Growing an approved Cook adds exactly the extra as a new line
- Shrinking one changes nothing on the list
